# Merenda plus

O objetivo deste projeto é desenvolver um sistema web de gestão de merenda escolar voltado para escolas públicas municipais, com a finalidade de melhorar a organização e o controle dos processos relacionados à alimentação dos estudantes. O sistema busca auxiliar no registro da demanda diária de merenda, no controle de estoque, no acompanhamento do consumo de alimentos e na redução de desperdícios, substituindo processos manuais por uma solução digital mais eficiente e acessível.

Além disso, o projeto pretende facilitar o trabalho da direção escolar e das merendeiras, oferecendo ferramentas que permitam maior controle das informações, melhor planejamento das refeições e geração de relatórios para apoio à gestão escolar. Dessa forma, a solução proposta contribui para uma administração mais organizada, transparente e funcional da merenda escolar dentro das instituições públicas de ensino.
